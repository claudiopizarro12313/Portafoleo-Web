## 🚀 About the Project

The website was built with a modern dark mode interface focused on user experience (UX) and performance. It allows visitors to explore my featured projects, learn about my tech stack, and reach out to me directly.

---

## ✨ Key Features

* **Responsive Design:** Optimized for mobile devices, tablets, and desktop computers.
* **Multi-Language Support:** Dynamic language switching (Spanish / English) powered by JavaScript.
* **Project Cards:** Direct links to GitHub source code and live demos.
* **Direct Contact:** Integration for quick email sending.

---

## 🛠️ Technologies Used

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling & Icons:** CSS Grid/Flexbox, FontAwesome
* **Deployment:** GitHub Pages
